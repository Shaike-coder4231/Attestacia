#Random Task Generator — Итоговая аттестация

**Автор:** Баженов Илья

## 📖 О проекте

**Random Task Generator** — это графическое приложение на Python, созданное в рамках итоговой аттестации. Оно помогает генерировать случайные задачи из разных категорий (учёба, спорт, работа), отслеживать их историю и управлять списком дел.

Приложение демонстрирует навыки работы с графическим интерфейсом (`tkinter`), файловым вводом-выводом (`JSON`), случайными числами (`random`) и системой контроля версий (`Git`).

## ✨ Основные возможности

| Функция - Описание |
| 🎯 **Генерация задач** - Случайный выбор задачи из выбранной категории или всех доступных. |
| 📜 **История задач** - Автоматическое сохранение каждой сгенерированной задачи с временной меткой. |
| 🔍 **Фильтрация** - Просмотр истории и генерация задач только по конкретному типу (учеба, спорт, работа). |
| ➕ **Добавление задач** - Возможность пополнять базу своими задачами с проверкой на пустую строку. |
| 💾 **Сохранение данных** - История сохраняется в файл `tasks_history.json` и загружается при запуске. |
| 🧹 **Управление историей** - Кнопка для полной очистки истории с подтверждением действия. |

## 🛠 Технологии

- **Язык:** Python 3.7+
- **Библиотеки:**
  - `tkinter` — для создания графического интерфейса
  - `random` — для генерации случайных задач
  - `json` — для сохранения и загрузки истории
  - `datetime` — для временных меток
- **Система контроля версий:** Git
